# Интеграция периферии Waveshare ESP32-P4-Module-DEV-KIT

В данном документе описана аппаратная реализация и программная интеграция интерфейсов платы в Linux.

---

## 1. Слот для карт памяти MicroSD (SDMMC)

### Аппаратная часть:
- Контроллер: Аппаратный блок SDMMC Host чипа ESP32-P4 (SDIO 3.0, поддержка 1-битного и 4-битного режимов шины).
- Линии подключения MicroSD:
  - `CLK`: **GPIO 43**
  - `CMD`: **GPIO 44**
  - `D0`: **GPIO 39**
  - `D1`: **GPIO 40**
  - `D2`: **GPIO 41**
  - `D3`: **GPIO 42**
  - `CD` (Card Detect): **GPIO 45**

### Интеграция в Linux:
1. **Режим блочного устройства:**
   Гипервизор на базе ESP-IDF инициализирует драйвер `esp_vfs_fat_sdmmc_mount` / `sdmmc_host`.
   Через виртуализированное MMIO блочное устройство (совместимое с VirtIO-blk или простейшим секторным LBA-интерфейсом) SD-карта пробрасывается в гостевой Linux как устройство `/dev/vda` или `/dev/sda`.
2. **Монтирование в системе:**
   В `/etc/fstab` и скрипте `/etc/init.d/rcS` предусмотрено автоматическое монтирование:
   ```bash
   mkdir -p /mnt/sdcard
   mount -t ext4 -o noatime /dev/vda1 /mnt/sdcard || mount -t vfat /dev/vda1 /mnt/sdcard
   ```
   Это дает возможность использовать гигабайты энергонезависимого пространства для установки дополнительных пакетов, компиляторов и файлов данных.

## 2. Экран и графика: MIPI-DSI (Фреймбуфер `/dev/fb0`)

### Аппаратная часть:
- Контроллер: MIPI-DSI Host (2 линии передачи данных D0/D1 + CLK, пропускная способность до 1.5 Гбит/с на линию).
- Поддерживаемые дисплеи: Waveshare 7.0-inch / 10.1-inch DSI LCD (1024×600, 1280×800) с интерфейсом I2C тачскрина (GT911).

### Архитектура графического вывода:
1. Гипервизор в фоновом режиме инициализирует контроллер DSI и выделяет буфер экрана (RGBA565 / RGB888) в верхней области физической PSRAM.
2. Для гостевого Linux регистрируется виртуальный драйвер фреймбуфера `simplefb` или VirtIO-GPU по фиксированному базовому адресу:
   ```dts
   framebuffer@90000000 {
       compatible = "simple-framebuffer";
       reg = <0x00 0x90000000 0x00 0x12C000>; /* 1024x600x2 = 1.2 MB */
       width = <1024>;
       height = <600>;
       stride = <2048>;
       format = "r5g6b5";
   };
   ```
3. Ядро Linux загружает драйвер `CONFIG_FB_SIMPLE=y`, активируя текстовую консоль `fbcon` и узел `/dev/fb0`.

## 3. Камера: MIPI-CSI

### Аппаратная часть:
- Контроллер: 2-lane MIPI-CSI Host, аппаратный ISP (Image Signal Processor) с поддержкой аппаратного сжатия H.264 / JPEG.
- Поддерживаемые сенсоры: OV5647, SC2336 (до 5 Мпикс).

### Схема работы:
Захват кадров и аппаратное сжатие H.264 выполняет сопроцессор на стороне ESP-IDF FreeRTOS, после чего сжатый видеопоток через кольцевой буфер и драйвер V4L2 (Video4Linux) передается в гостевую систему.

---

## 4. USB 2.0 High-Speed OTG (480 Мбит/с)

### Аппаратная часть:
- Чип ESP32-P4 содержит интегрированный USB 2.0 High-Speed PHY (выводы `USB_DP` / `USB_DM` на GPIO 19 / 20).
- Поддерживает режимы:
  - **Host Mode:** подключение внешних USB Flash-накопителей, клавиатур, мышей, USB-Ethernet адаптеров (AX88772/RTL8152).
  - **Device Mode:** эмуляция композитного USB устройства (USB CDC-ACM Serial + USB RNDIS/CDC-Ethernet).

## 5. Сеть: Ethernet EMAC и Wi-Fi (ESP-Hosted)

### 5.1 Проводной Ethernet 10/100 Мбит/с
- Встроенный MAC: ESP32-P4 EMAC контроллер с интерфейсом RMII.
- Внешний PHY: IP101GRI / LAN8720A на модуле Waveshare.
- Сетевые пакеты L2 передаются через TAP/TUN туннель между ESP-IDF LwIP и гостевым сетевым интерфейсом Linux `eth0`.

### 5.2 Сетевой туннель SLIP / PPP через последовательный порт
Для простоты и автономности (даже без подключенного Ethernet кабеля) поддерживается работа сетевого протокола **SLIP (Serial Line IP)** прямо поверх интерфейса UART / USB-Serial-JTAG:
```bash
# На хост-машине (Linux PC):
sudo slattach -p slip -s 115200 /dev/ttyUSB0 &
sudo ifconfig sl0 192.168.7.1 pointopoint 192.168.7.2 up
sudo sysctl -w net.ipv4.ip_forward=1
sudo iptables -t nat -A POSTROUTING -s 192.168.7.2 -j MASQUERADE

# На плате ESP32-P4 (в гостевом Linux):
ifconfig sl0 192.168.7.2 pointopoint 192.168.7.1 up
route add default gw 192.168.7.1
echo "nameserver 8.8.8.8" > /etc/resolv.conf
curl https://wttr.in/Moscow?format=3
```
Это дает плате доступ в глобальный интернет для загрузки веб-страниц, API и пакетов.
