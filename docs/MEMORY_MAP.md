# Карта памяти и разметка Flash/PSRAM для ESP32-P4 Linux

## 1. Карта Flash-памяти (16 МБ SPI Flash)

Плата Waveshare ESP32-P4-Module-DEV-KIT оснащена 16 МБ NOR Flash. Разметка партиций оптимизирована под размещение прошивки-гипервизора, ядра Linux со встроенным rootfs (initramfs) и скомпилированного дерева устройств (DTB):

| Смещение (Offset) | Размер | Имя раздела | Тип / Подтип | Назначение |
|---|---|---|---|---|
| `0x000000` | 8 КБ (`0x2000`) | `bootloader` | - | Вторичный загрузчик ESP-IDF (Second stage bootloader) |
| `0x002000` | 28 КБ (`0x7000`) | `partition_table` | - | Таблица разделов ESP-IDF (`partition-table.bin`) |
| `0x009000` | 24 КБ (`0x6000`) | `nvs` | `data, nvs` | Хранилище настроек NVS |
| `0x00F000` | 4 КБ (`0x1000`) | `phy_init` | `data, phy` | Калибровочные данные радио/PHY |
| `0x010000` | 1 МБ (`0x100000`) | `factory` | `app, factory` | Бинарник гипервизора/SBI загрузчика (`esp32p4-linux-boot.bin`) |
| `0x110000` | 14 МБ (`0xE00000`) | `kernel` | `data, 0x58` | Образ ядра Linux с Initramfs (`kernel/Image`) |
| `0xF10000` | 64 КБ (`0x10000`) | `dtb` | `data, 0x58` | Бинарное дерево устройств (`dtb.bin`) |
| `0xF20000` | 896 КБ (`0xE0000`) | `reserved` | `data, custom` | Резерв / энергонезависимые данные |

## 2. Карта оперативной памяти (PSRAM и гостевое пространство)

### 2.1 Физическая память ESP32-P4
- Внутренняя SRAM SoC: ~768 КБ (используется ESP-IDF для стека задач гипервизора, кэшей и IRAM).
- Внешняя PSRAM: 16 МБ или 32 МБ (подключена по 200 МГц Hexa-SPI шине, кэшируется через аппаратный кэш контроллера).

### 2.2 Виртуальное адресное пространство Linux Guest (RISC-V)

Внутри гостевой системы память структурирована в соответствии со стандартной спецификацией RISC-V:

| Диапазон гостевых адресов | Размер | Назначение |
|---|---|---|
| `0x80000000` - `0x80FEFFFF` | ~15.93 МБ | Физическая память ядра и пользовательских процессов гостевого Linux |
| `0x80FF0000` - `0x81000000` | 64 КБ | Буфер FDT (Flattened Device Tree), передаваемый ядру в регистре `a1` |
| `0x10000000` - `0x100000FF` | 256 Б | MMIO: 16550A совместимый UART (консоль `ttyS0`) |
| `0x0C000000` - `0x0FFFFFFF` | 64 МБ | MMIO: Контроллер прерываний SiFive PLIC |
| `0x11000000` - `0x1100FFFF` | 64 КБ | MMIO: Таймер SiFive CLINT (генератор прерываний таймера) |
| `0x11100000` - `0x11100FFF` | 4 КБ | MMIO: Syscon (регистры программной перезагрузки и выключения питания) |
